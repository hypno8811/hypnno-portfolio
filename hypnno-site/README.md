# Hypnno — Loose Minimal Concept

A stripped-back artist site inspired by loose fashion/store layouts: floating covers, lots of negative space, minimal navigation and a cinematic release-focus transition.

## Main interaction
Click any floating cover on the first screen. The artwork FLIP-animates into the center, the page darkens, and the title/description reveal with vertical smear motion. A real WebGL shader layer adds restrained streaking during the transition.

## Notes
- Existing Hypnno assets and links are reused.
- “Play Preview” currently opens the listening destination because no direct audio preview file was provided.
- No extra particles, ornamental UI or card borders were added.
